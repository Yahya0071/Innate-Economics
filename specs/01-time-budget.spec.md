# مواصفات التجربة 1: ميزانية نبضات اليوم (The Currency of Life)

## 1. الهوية والهدف البيداغوجي
* **الاسم الفطري:** ميزانية نبضات اليوم
* **المفهوم الاقتصادي الكامن:** الندرة (Scarcity)، تكلفة الفرصة البديلة (Opportunity Cost)، تناقص العائد الحدي (Diminishing Marginal Returns)، وتراكم رأس المال (Capital Accumulation).
* **الشعار الذهني:** «كل ساعة تنفقها في كسب اليوم هي ثمن أداة لم تصنعها لغدك، وجسدك ليس آلة».

---

## 2. قاعدة الحلقات الأربع (The 4 Loops)

### الحلقة 1: الاصطدام بالمأزق (The Micro-Dilemma)
* **المشهد:** اليوم الأول في واحة معزولة. لديك 16 ساعة يقظة وطاقتك 100%.
* **القرار المباشر:** كيف توزع ساعاتك الـ 16 اليوم بين 3 خيارات لا رابع لها؟
  1. **الكسب المباشر ($W$ - جمع الثمار):** طعام فوري لبطنك اليوم.
  2. **بناء الأداة ($T$ - نسج شبكة الصيد):** لا يُؤكل اليوم، ولكنه يضاعف كفاءة كل ساعة غداً.
  3. **الراحة والاسترداد ($R$ - استعادة الأنفاس):** صيانة محرك الجسد لئلا ينهار غداً.
* **القيد الصارم:** $W + T + R = 16$ ساعة، بدون أي فائض أو عجز في الزمن.

### الحلقة 2: الارتداد النظامي (Systemic Consequence)
* **فخ الانهماك الأعمى:** المستخدم يضع 14 ساعة عمل فوري ليجمع أقصى كمية طعام. النتيجة: يستيقظ في اليوم التالي بطاقة 30% فقط، فتنتج ساعته الواحدة ثلث ما كانت تنتجه، ويكتشف أن الساعات الأخيرة من اليوم كانت مجهدة بعديم الجدوى.
* **فخ الحلم المؤجل:** يضع 14 ساعة في بناء الأداة؛ يأتي المساء بلا طعام يكفي العشاء، فينام جائعاً وتتدهور صحته.

### الحلقة 3: العبث الحر (Sandbox Simulation)
* محاكاة تمتد لـ 7 أيام متتالية.
* منزلق ثلاثي الأبعاد مقيد زمنياً (Tri-slider) بمجموع 16 ساعة.
* لوحات بيانية وتفاعلية حية تعرض:
  - مخزون الغذاء المتراكم.
  - مؤشر حيوية الجسد والتركيز.
  - نسبة اكتمال أدوات الغد (أيدي مجردة -> عصا مشذبة -> سلة حبال -> شبكة صيد متطورة).
* أزرار إستراتيجيات تجريبية سريعة:
  - «المدمن على العمل» (Workaholic)
  - «المستثمر الحالم» (Premature Capitalist)
  - «المتوازن الفطن» (The Balanced Craftsman)

### الحلقة 4: البصيرة الصامتة (The Crystallization)
* تتبلور الحكمة في شاشتين موجزتين:
  1. **الجهد ليس خطياً:** الساعات الأولى من العمل تثمر أكثر من الساعات الأخيرة (تناقص العائد الحدي).
  2. **الأداة تعتق الإنسان:** بدون استثمار وقت في صناعة الأداة، يظل الإنسان رهين الشقاء اليدوي إلى الأبد (تراكم رأس المال).
* شارة هامشية اختيارية بالمصطلحات الاقتصادية الأكاديمية المقابلة.

## 3. محرك المحاكاة الرياضي (`src/engine/time-budget/`)

### متغيرات الحالة (State Interface)
```typescript
export interface TimeBudgetState {
  day: number;                    // اليوم الحالي (1..7)
  energy: number;                 // طاقة الجسد (0..100)
  foodStock: number;              // رصيد الطعام المتراكم
  toolProgress: number;           // نسبة إنجاز الأداة الحالية (0..100)
  toolTier: number;               // مستوى الأداة (0..3)
  isAlive: boolean;               // قيد الحياة
  history: DayRecord[];           // سجل الأيام السابقة
}

export interface DayAllocation {
  workHours: number;              // ساعات الكسب المباشر
  toolHours: number;              // ساعات بناء الأداة
  restHours: number;              // ساعات الراحة
}
```

### القوانين الرياضية (Invariants & Formulas)
1. **قيد الساعات:** $W + T + R = 16$ (حيث $W, T, R \ge 0$).
2. **تناقص الإنتاجية الحدية بالساعة:**
   - الساعات 1 إلى 4: عائد أساسي $1.5$ وحدة/ساعة.
   - الساعات 5 إلى 8: عائد أساسي $1.0$ وحدة/ساعة.
   - الساعات 9 إلى 12: عائد أساسي $0.6$ وحدة/ساعة.
   - الساعات 13 إلى 16: عائد أساسي $0.25$ وحدة/ساعة.
3. **معامل الأداة المضاعف ($M$):**
   - مستوى 0 (أيدي مجردة): $1.0\times$
   - مستوى 1 (عصا مشذبة): $1.5\times$
   - مستوى 2 (سلة متينة): $2.2\times$
   - مستوى 3 (شبكة متطورة): $3.2\times$
4. **معامل الطاقة الحالية ($E$):**
   - الإنتاج الفعلي = العائد الأساسي $\times M \times (0.3 + 0.7 \times \frac{E}{100})$
5. **ديناميكية الطاقة:**
   - استهلاك العمل: $-4.5\%$ لكل ساعة عمل.
   - استهلاك بناء الأداة: $-3.5\%$ لكل ساعة.
   - استرداد الراحة: $+7.5\%$ لكل ساعة راحة.
   - الطاقة لليوم التالي = $\text{clamp}(E_{current} - \text{burn} + \text{rest}, 10, 100)$.
6. **الاستهلاك اليومي الحتمي:**
   - يتطلب البقاء حياً استهلاك $2.0$ وحدة طعام كل ليلة.
